# cqrs-gen — Code Generator

[![Go Reference](https://pkg.go.dev/badge/github.com/larsartmann/go-cqrs-lite/cmd/cqrs-gen/v2.svg)](https://pkg.go.dev/github.com/larsartmann/go-cqrs-gen/v2)

CLI tool that scans Go source files for `//cqrs:command` or `//cqrs:query` marker comments on type declarations and emits typed handler-registration boilerplate (`handlers_gen.go`). Eliminates repetitive `RegisterTyped` call sites.

## Install

```bash
go install github.com/larsartmann/go-cqrs-lite/cmd/cqrs-gen/v2@latest
```

## Usage

Add marker comments to your command/query structs:

```go
//cqrs:command
type CreateUserCmd struct {
    *command.BasicCommand
    Name  string
    Email string
}

//cqrs:query
type GetUserQuery struct {
    *query.BasicQuery
    UserID string
}
```

Run the generator:

```bash
# Generate command handlers (default)
cqrs-gen -output handlers_gen.go -pkg myapp

# Generate query handlers
cqrs-gen -type query -output query_handlers_gen.go -pkg myapp
```

This produces:

```go
// Code generated by cqrs-gen. DO NOT EDIT.
package myapp

func RegisterCommandHandlers(d *command.Dispatcher, h *Handlers) {
    command.RegisterTyped(d, "create.user.cmd", h.HandleCreateUserCmd)
    // ...
}
```

## Flags

| Flag      | Default           | Description                        |
| --------- | ----------------- | ---------------------------------- |
| `-type`   | `command`         | Handler type: `command` or `query` |
| `-output` | `handlers_gen.go` | Output file path                   |
| `-pkg`    | (from dir)        | Package name for generated file    |

## Dependencies

Zero external dependencies — uses only the Go standard library (`go/ast`, `go/parser`).
