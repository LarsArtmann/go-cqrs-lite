# cqrs-gen — Code Generator

[![Go Reference](https://pkg.go.dev/badge/github.com/larsartmann/go-cqrs-lite/cmd/cqrs-gen/v4.svg)](https://pkg.go.dev/github.com/larsartmann/go-cqrs-lite/cmd/cqrs-gen/v4)

CLI tool that scans Go source files for `cqrs` markers on type declarations and
emits typed handler-registration boilerplate (`handlers_gen.go`). It removes
repetitive `RegisterTyped` / `Subscribe` call sites for commands, queries, and
events.

## Install

```bash
go install github.com/larsartmann/go-cqrs-lite/cmd/cqrs-gen/v4@latest
```

## Markers

A marker carries the **type string** that will be registered. Two equivalent
forms are supported — a leading comment, or a struct tag on a blank `_` field.

Comment marker (the identifier after the kind is the registered type):

```go
//cqrs:command user.create
type CreateUserCmd struct {
    *command.BasicCommand
    Name  string
    Email string
}

//cqrs:query user.get
type GetUserQuery struct {
    *query.BasicQuery
    UserID string
}

//cqrs:event user.created
type UserCreatedPayload struct {
    UserID string
}
```

Struct-tag marker (useful when you want to keep the type string next to the
field list):

```go
type CreateUserCmd struct {
    _    struct{} `cqrs:"command:user.create"`
    Name string
}
```

When both are present on the same type, the comment marker wins.

## Usage

Run the generator once per kind. Each invocation scans the given paths (`.`
by default) and writes one output file.

```bash
cqrs-gen -type=command -output=commands_gen.go -pkg=myapp ./...
cqrs-gen -type=query    -output=queries_gen.go    -pkg=myapp ./...
cqrs-gen -type=event    -output=events_gen.go     -pkg=myapp ./...
```

### Generated output

The generator emits **one `Register<Type>Handler` function per marked struct**
(not a single aggregate function), so you wire only the handlers you need:

```go
// Code generated by cqrs-gen. DO NOT EDIT.

package myapp

import (
	"context"

	"github.com/larsartmann/go-cqrs-lite/command/v4"
)

// RegisterCreateUserCmdHandler registers a typed handler for user.create commands.
func RegisterCreateUserCmdHandler(d *command.Dispatcher, handler func(context.Context, *CreateUserCmd) error) error {
	return command.RegisterTyped(d, "user.create", handler)
}
```

Query handlers are generic over the result type (`RegisterXxxHandler[R any]`);
event handlers take a `event.Subscriber` + `codec.Codec` and decode the payload
for you via `event.DecodePayload`.

## Flags

| Flag      | Default           | Description                                                               |
| --------- | ----------------- | ------------------------------------------------------------------------- |
| `-type`   | `command`         | Handler kind: `command`, `query`, or `event`                              |
| `-output` | `handlers_gen.go` | Output file path                                                          |
| `-pkg`    | scanned package   | Package name for the generated file (defaults to the source package name) |

Trailing args are the paths to scan (recursively). Test files (`*_test.go`) and
`vendor` / `node_modules` / `testdata` / hidden directories are skipped
automatically. If two scanned structs share a name, the first wins and a
warning is printed (a single file cannot hold two `RegisterXxxHandler` funcs).

## Dependencies

Zero external dependencies — uses only the Go standard library
(`go/ast`, `go/parser`, `go/format`). Output is always passed through
`go/format`, so the generated file is valid, gofmt-clean Go.
