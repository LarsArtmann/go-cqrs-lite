## 5. Module Reference (quick lookup)

### Core (Layer 0–3)

| Module             | Import                                                                                       | One-liner                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------ | -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`               | `id/v4`                                                                                      | Branded IDs: `id.Of[T]` = `cbid.ID[T, ulid.ULID]`. All 8 markers exported (`StreamMarker`, `EventMarker`, `CommandMarker`, …) for `BrandNamer` integration. Custom via `id.Of[struct{}]`. `ActorID` (kinds `user`/`bot`/`system`/`service`, wire format `"kind:raw"`, `PrefixedString`, `ParseActorID`, `Validate`, CBOR-safe via `MarshalBinary`).
