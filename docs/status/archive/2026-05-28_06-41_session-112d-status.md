3. **Missing BDD tests** — Value types (Version, SchemaVersion, OutboxStatus, Pagination) lack Ginkgo BDD coverage.
4. **No benchmarks** — Zero benchmark tests for storage backends or E2E throughput. Can't measure performance regressions.

### Architecture

5. **Pebble LoadToTimestamp does full scan** — Loads ALL events then filters by timestamp. Needs iterator bounds.
6. **No async writes for Pebble** — Synchronous writes limit throughput for high-volume scenarios.
7. **No projection parallel processing** — Events processed sequentially per projection. Goroutine pool would improve throughput.
8. **No catch-up projection runner** — Current replay is naive. Need start-from-checkpoint → replay → live-switch with gap detection.

### DevEx / Infrastructure

9. **Pre-commit hook is destructive** — Reformats files then fails to commit, leaving dirty working tree. Fix BuildFlow to either commit formatting changes or not reformat.
10. **CI not parallelized** — Single job runs all modules. One job per module would be 5-10x faster.
11. **No performance regression CI** — Benchmarks should run on every PR to catch regressions.
12. **Example apps are stale** — example/user/ doesn't demonstrate full CQRS stack. No smoke tests.
