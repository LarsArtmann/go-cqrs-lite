🔍 Complete Findings

F1. Idempotency Store — Misplaced SPLIT-BRAIN

Problem: cqrs-htmx/idempotency.go implements a CQRS reliability primitive (dedup for at-least-once delivery) that belongs in the core library. go-cqrs-lite's own gap analysis (framework-os-gaps.html, item A3) identifies this as the highest-value missing piece: 

"A small idempotency-key store + a command middleware (check-seen,
store-result-on-success) is a classic framework primitive that's small
to build and large in value."

Action taken: Created go-cqrs-lite/idempotency/ module with Store interface, MemoryStore, ErrDuplicate. Verified in both workspace and CI-isolation modes.

Remaining: Add CommandIdempotency middleware. cqrs-htmx keeps its local copy until upstream tags a release (CI constraint: GOWORK=off single-repo checkout).

F2. SSE Wire-Format Primitives — Duplicated DUPLICATION

Problem: Both repos implement the same SSE protocol primitives:

Primitive go-cqrs-lite/transport/http cqrs-htmx
SSEEvent struct ✅ Type/ID/Data/Retry ✅ Event/ID/Data/Retry
WriteSSEEvent ✅ bytes.Buffer ✅ Zero-alloc []byte append
ParseSSEEventID ✅ Plain string type ✅ Branded SSEEventID type
WriteSSEHeartbeat ✅ ✅ (in SSEStream.Heartbeat)

Assessment: The cqrs-htmx versions are better (branded types, zero-alloc). But transport/http is the canonical transport home. Same release-dependency blocker as idempotency.

Recommendation: When go-cqrs-lite next tags, promote the cqrs-htmx wire-format improvements upstream, then delegate. The HTMX-specific layers (Broadcaster, SSEStream, ACK protocol) stay in cqrs-htmx.

F3. What's CORRECTLY Placed VERIFIED

  • ack.go — CommandAck data model is transport-agnostic, but the hook factories (BroadcastOnAck) are HTTP-coupled (*http.Request). Correctly in cqrs-htmx.
  • structured_error.go — RFC 7807 shape is HTTP-specific. Correctly in cqrs-htmx.
  • fanout.go — Internal generic fanOut[T] utility used only by SSE/WS broadcasters. Correctly in cqrs-htmx.
  • csrf_*.go, ratelimit_*.go, security.go — HTTP-only concerns. Correctly in cqrs-htmx.
  • usermgmt/ — Event-sourced domain (User, Tenant, Bot, Membership). Correctly a separate module — it's an opinionated domain, not a library primitive.
