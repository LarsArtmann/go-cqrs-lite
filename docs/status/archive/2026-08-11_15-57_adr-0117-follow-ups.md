## a) FULLY DONE

### 1. Fixed Recorder Version Tracking (Critical Correctness Bug)

**Problem:** The Recorder tracked versions in an ephemeral in-memory `map[string]event.Version`. On process restart, the counter reset to 0, and the next `AppendBatch` would collide with existing events or silently corrupt the stream (MemoryStore trusts caller versions verbatim — no re-stamping).

**Fix applied:**
- Changed `NewRecorder` signature from `event.EventSink` to `event.Store` (requires both `EventSink` + `EventSource`). This is a **breaking API change** for consumers who were passing sink-only types.
- `nextVersion` now lazy-hydrates from the EventSource on first access to each stream. If the stream doesn't exist yet (`errors.Is(err, event.ErrStreamNotFound)`), it seeds version 0.
- Writes use `Save()` with optimistic concurrency (`expectedVersion = version - 1`) instead of `AppendBatch()`, preventing duplicate versions on concurrent writes.
- Extracted `seedVersion` helper to keep `nextVersion` under the lint complexity threshold (nestif).
- Updated `closedSink` test mock to implement all 6 `EventSource` + `EventSink` methods.

**Test coverage:**
- Added `TestRecorder_SurvivesRestart_VersionContinuity` — proves that a brand-new Recorder continues version numbering from where the store left off (versions 1-4 across two "processes").
- All 16 pre-existing tests still pass.
- Race detector clean.

**Files changed:** `commandlifecycle/recorder.go`, `commandlifecycle/recorder_test.go`

## d) TOTALLY FUCKED UP

### Breaking API Change on `NewRecorder`
I changed `NewRecorder(sink event.EventSink, ...)` to `NewRecorder(store event.Store, ...)`. This is a **breaking change** for any consumer who was passing an `EventSink`-only type. Since `commandlifecycle/v4.0.0` has not been tagged yet, no external consumer is affected, but any internal code or examples that used the old signature would break at compile time. The `event.Store` interface requires both `EventSink` and `EventSource`, so consumers passing a write-only sink will get a compile error.

**Mitigation:** Since this module has no published tag, the breakage is contained to the workspace. All internal callers (tests, system package) were updated in the same change.
