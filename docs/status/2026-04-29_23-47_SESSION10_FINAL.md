## Architecture Decisions Made

1. **Coordinated releases acceptable** — The `core ↔ memory/testhelpers` circular dependency is documented and accepted. The `replace` directive pattern is standard for Go monorepos.

2. **DispatchTyped[T] is sufficient** — Making `Query` generic would require breaking all handlers and type erasure at the registry. Runtime type assertion is one line and works well.

3. **Generic middleware core skipped** — Go's defined handler types (`command.Handler`, `event.Handler`) prevent clean generic unification. Adapter boilerplate equals original code.

4. **CatalogBuilder and Registry remain separate** — Behavioral divergence (merge vs overwrite) makes consolidation increase complexity rather than reduce it.
