  (`id/monotonic_test.go:19`) asserts strict ordering across 100 sequential
  IDs. Any sharding must preserve this for single-goroutine generation.
- Candidate designs considered but not built:
  1. `sync.Pool` of per-goroutine monotonic readers — fastest, but Pool can
     hand back a different reader after GC, which can break same-millisecond
     monotonicity mid-sequence.
  2. Fixed shard count (e.g. 16), each with own mutex + entropy, selected by
     a per-goroutine stable key — deterministic, but cross-goroutine
     same-millisecond ordering is NOT guaranteed (uniqueness still is, via
     random 80-bit suffix).
- Open question blocking implementation: does anything actually depend on
  cross-goroutine same-millisecond ID ordering? (Event ordering in this
  repo uses stream `Version`, not ID order — but the test asserts it.)

## d) TOTALLY FUCKED UP (all caught & fixed in-session — plus 1 open risk)

   implementation multiplied `ops` by `filterSelectivity(...)`. This flipped
   engine routing for `benchFilterQuery` from SQLite to Memory, and
   `TestTypedReader_CursorPagination` failed with duplicate IDs across pages
   (10 unique of 50). Caught by running the FULL metaengine suite, not just

   `cost.go` documents why (discounts can flip engine ranking in unexpected
   ways). Lesson: cost-model changes must always be followed by the full

   and `command/asrecord.go` / `query/asrecord.go` intentionally pass `""` as
   streamType — validation would have rejected a legitimate pattern. Reverted
   to non-breaking `Validate()` method before anything shipped. Lesson: grep
   call sites BEFORE changing a signature, not after.

3. **Edit lost to the auto-commit daemon.** One edit to `cost.go` failed with
   "file modified since last read" (daemon committed mid-session). Re-read and
   re-applied. The daemon also committed my in-flight work as
   `490f2786a "docs+metaengine: surface volume default and fix graph traversal
   cost"` and modified `CHANGELOG.md` + `storage/sql/validate_fuzz_test.go`
   which I did NOT author and did NOT touch.

4. **OPEN RISK — Split()/Validate() inconsistency (needs 5-min fix):**
   `Validate("/01JTEST")` returns nil (empty streamType allowed — the
