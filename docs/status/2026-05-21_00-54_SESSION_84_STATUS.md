## E. WHAT WE SHOULD IMPROVE 🔧

### Split Brains (Critical)
- **`CatalogMeta` triplicated** across `event`, `command`, `query` packages. All deprecated but still exported. The `event.CatalogMeta` has an extra `AggregateType` field. Should be consolidated or removed.
- **Middleware triple repetition** — 18 near-identical functions (6 concerns × 3 CQRS dimensions). Go generics limitation, but the maintenance burden is real.

### Architecture
- **Error classification via `init()`** — Hidden global side effects, no conflict detection. Should be explicit setup.
- **`storage/dialect.go` uses `any`** — 3 methods return/accept `any` (FormatTime, ScanTimeDest, ParseTime). Violates "no any" project rule.

### Missing Validation
- `event.Type("")` and `event.AggregateType("")` bypass validation — no `Parse*` constructors.
- `sync.NewVectorClockFromMap` accepts negative counters silently.
- `catalog.ServiceID("")` bypasses validation — no `Parse*` constructor.
