### `storage/turso.OpenTemp("")` — Stale Database Bug

- **What:** `OpenTemp("")` creates `os.TempDir()/test.db` — a **fixed, non-unique path**.
- **Impact:** Running turso tests twice (or after a crashed run) causes `database is corrupt: invalid page size` failures.
- **Root cause:** The empty-string fallback in `OpenTemp` should use a temp dir, not a fixed filename.
- **Workaround:** `rm /tmp/test.db*` before running.
- **Severity:** Medium — affects developer experience and CI reliability. Example tests use this path; regular tests correctly use `t.TempDir()`.
- **NOT FIXED in this release.**

## e) WHAT WE SHOULD IMPROVE 📈

### Process Improvements

1. **Automate the release** — The tag-cutting process is manual and error-prone. A `nix run .#release` app that detects changed modules and cuts tags would eliminate 30 minutes of manual work.

2. **Fix `OpenTemp` before next release** — The stale-database bug will bite again. One-line fix: use `t.TempDir()` in example tests, or have `OpenTemp("")` generate a unique filename.

3. **Push tags as part of the release flow** — Currently tags are local-only until manually pushed. The release process should include a push step (or at minimum, a prominent reminder).

4. **Run `go mod tidy` post-tag** — Bump internal dependency refs to the new version. This keeps `go.mod` files honest about what version they depend on.

5. **Tag consistency check** — `projectionhost/v3.5.0` was tagged early, creating a split-brain. A pre-release check that all tags point to the same commit would catch this.

### Code Quality

6. **Catalog module complexity** — `eventcatalog.Export()` has cyclop 26 (suppressed with nolint). It's a straight-line pipeline — could be refactored into a `writeSection(name, items, writer)` helper.

7. **EventCatalog YAML tag format** — 5 fields use kebab-case/snake_case YAML tags (suppressed with `//nolint:tagliatelle`). This is intentional (EventCatalog.io format), but the suppression adds noise. Consider a tagliatelle config override for the eventcatalog package.

8. **Embedded struct ordering** — `BaseConfig` and `baseConfigFM` embedded fields trigger `embeddedstructfieldcheck`. Fixed by moving to top + blank line, but this fights with Go's conventional field grouping. Acceptable tradeoff.

### Architecture

9. **Blind store encoding stamps (ADR-0044)** — The biggest gap. Until implemented, codec changes are asymmetric (events self-describing, blind stores not). This blocks safe default codec changes in v4.

10. **Coverage gaps** — `stack/postgres` shows 0% locally (skips without `POSTGRES_TEST_DSN`). Bundle layers (stack presets) have lighter coverage by design (contract tests + happy paths). Consider a CI matrix that runs Postgres tests.
