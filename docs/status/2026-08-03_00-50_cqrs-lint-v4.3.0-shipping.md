## e) WHAT WE SHOULD IMPROVE

### 1. The status report anti-pattern is systemic

Two consecutive status reports (the prior session's and my initial diagnosis) contained claims presented as fact that were actually unverified. The root cause is the same each time: trusting intermediate state ("Nix dry-run passes", "3 files uncommitted") without re-running the verification. **Every status report should include the exact command + output that verifies each claim.** No command output = no claim.

### 2. Version constant should be derived from tag, not hardcoded

The version constant in `main.go` has been wrong for the entire v4 release track. Every release requires a manual edit to bump the number, and it's already been forgotten once. Two better approaches:

- **Build-time derivation**: `git describe --tags` at build time, injected via ldflags (like commitHash already is)
- **CI gate**: A test that asserts `version` constant matches the latest tag semver

### 3. The Nix build should be part of the test suite, not an afterthought

The prior session implemented ldflags changes, marked them done, and never ran `nix build .#cqrs-lint`. The vendorHash was stale for the entire session. If Nix build were part of the standard verification loop (not just `go test`), this class of staleness would be caught immediately.

### 4. SystemNix flake input is a distribution blind spot

The binary at `/run/current-system/sw/bin/cqrs-lint` was 86 commits behind HEAD. Nobody noticed because the version constant was also stuck at `0.2.2`, so the stale binary reported the same version as the stale source. The SystemNix flake input for `go-cqrs-lite` should be bumped as part of the release process, not left to chance.

### 5. ConfigFeatures round-trip has no automated test

The ConfigFeatures → ResolveFeatureProfile → FeatureProfile → ToConfigFeatures → ConfigFeatures round-trip should have a property test that verifies no information loss. The gap I fixed (Transport/ServerLocal missing from the cycle) would have been caught by such a test.
