02Findings

Correctness

Materialize silently drops Undetermined tombstones

stack/materialize.go:126-147

The tombstone switch handles TombstoneTombstoned and TombstoneActive (rebirth) but omits TombstoneUndetermined, which falls through to a silent return nil. An undetermined-status event is therefore not projected. This may be intentional ("can't decide → no-op") but the gap should be explicit, not implicit.

Fix Add case event.TombstoneUndetermined: return nil (documented) or log a warning. Makes the exhaustive switch compile-clean and the intent visible.
Correctness

reflect.Kind switch missing many cases

storage/view_store_auto.go:159

The auto view-store column-type mapper switches on reflect.Kind without cases for Int8/16, Uint8/16, Array, Struct, Map, etc. An unsupported kind hits the default silently rather than erroring. Better to fail loudly on an unsupported type than to produce a wrong column.

Type safety

context.Context stored in a struct

watermill/event_bus.go:40

The EventBus struct holds a context.Context. Contexts should flow through method parameters to preserve cancellation semantics. Refactor to accept ctx per-call.

API hygiene

Internal use of deprecated query.Handler

middleware/generic.go:85

The library's own code references its deprecated query.Handler. Migrate the call site to TypedHandler[Q,R] so the codebase doesn't depend on its own deprecated surface.

Architecture

Test-dependency leak & grpc workspace conflict

event/command/decider/watermill → storage/memory; transport/grpc genproto

Two structural items (detailed in the architecture-review and go-modularize reports): core modules carry storage/memory as a direct production require (test-only), and transport/grpc can't join go.work due to a genproto ambiguous-import. Neither affects runtime correctness; both affect build hygiene.

Config / hygiene

Over-aggressive linter set & stale config

.golangci.yml (makezero/noinlineerr/exhaustruct); 3 dead build tags (removed); file-size gate flags generated .pb.go

~135 of 200 lint findings are stylistic noise. Tuning the config (disable noinlineerr, scope makezero/exhaustruct out of tests) clears them and surfaces real issues. Full breakdown in the code-quality-scan report.
