Critical Issues Found & Fixed

The "mixed streams" promise was a lie Critical Fixed

DecodePayload[T](evt, codec) validated encoding match and rejected mismatched events. Migrating JSON→CBOR broke old events silently. The schema.Validator already had this dispatch internally (decoderFor), but the public decode API did not.

Fix: Added codec.ForEncoding(enc) + event.DecodePayloadAuto[T](evt) — dispatches based on each event's encoding stamp. Mixed JSON+CBOR streams now decode correctly.

gRPC query service had ZERO test coverage Critical Fixed

The WithCodec option was added to RegisterQueryService and NewQueryClient, but no query_test.go existed. The codec injection was completely untested.

Fix: Added 4 tests: JSON round-trip, CBOR round-trip, handler error propagation, codec mismatch detection.

Non-deterministic AutoDetect test Critical Fixed

TestAutoDetect_UnknownIsRaw accepted EITHER Raw OR CBOR — it didn't assert actual behavior. For 0xff bytes, AutoDetect always returns CBOR (byte ≥ 0x80), but the test was uncertain.

Fix: Split into two deterministic tests: high bytes → CBOR (asserted), genuinely unknown (0x1f) → Raw (asserted).

Moderate Issues Found & Fixed

DefaultCodec concurrency contract undocumented High Fixed

Mutable package-level var without documenting the "set once at startup" contract. Users could hit a data race if mutating after goroutines start creating events.

Fix: Documented the concurrency contract clearly: "set ONCE at program startup, BEFORE any goroutine creates events."

Encryption encoding bug fix lacked integration test High Fixed

The encoding-preservation bug fix (CBOR events losing their stamp through encrypt/decrypt) only had unit-level middleware tests — no end-to-end integration test.

Fix: Added integration test in integration/encryption/ verifying CBOR events survive encrypt→bus→decrypt with encoding preserved and DecodePayloadAuto dispatch.

Broken doc references in AGENTS.md Pre-existing Fixed

The codec asymmetry table referenced snapshot.WithCodec, command.TypedStore, command.WithTypedCodec — none of which exist. The doc-check caught these.

Fix: Corrected to actual APIs (positional constructor args).

Remaining Considerations (Not Blocking)

  1. gRPC command payload serialization
    Command client doesn't serialize domain payload over gRPC (only type + metadata). Pre-existing limitation, not from codec work. Would need a payload field + codec on CommandEnvelope.
  2. v4 blind-store encoding stamps (ADR-0044)
    kv/snapshot/command/query stores have no encoding stamp. Switching defaults would silently break data. Envelope wrapper proposed for v4.
  3. Size() partial-failure paths
    The -1 return paths for partial encode failures (JSON succeeds, CBOR fails) are practically unreachable — both codecs handle all standard Go types. Defensive code only.
