Scope and Method

Every file under system/ visited one at a time — 29 source files, 27 root test files, plus system/integration/ (duckdb sub-module), README, go.mod replaces, and the flake publish path. Cross-module verification: decider/load.go (proves the cache-staleness path), metaengine/execute.go (proves the Count-input collision), id/stream_type.go (snapshot key symmetry), watermill/event_bus.go (close semantics). Baseline and post-fix gates: build + vet + race via the $HOME fallback caches (the /mnt/buildcache host mount is broken — repair ticket routed).

P1 — Correctness (5)

P1-1 · CachedEventStore never invalidated on write fixed a211ebc
system/cache.go:34-44 · regression: cache_test.go

Save/AppendBatch delegated straight to the wrapped store, leaving stale entries in the read-through Load cache forever. Because decider.Repository folds state via store.Load, any deployment with Cache.Capacity > 0 replayed the pre-write snapshot on every decision after the first write — permanently stale aggregates, silently. Fix: evict the stream key after each successful write; failed writes keep the still-valid entry.

P1-2 · Count projections collide on shared CountInput routed
system/runtime.go:157-171 + metaengine/execute.go:27-36

ExecuteTyped dispatches by input type; every Count() projection shares CountInput, so a second Count() registration silently shadows the first. GetCount's name parameter only feeds error messages. Fixing requires named dispatch in metaengine (cross-module, exported-behavior change) → proposal docs/adr/2026-08-17_system-v4-review-proposals.md.

P1-3 · Bus selection random per boot; only first-iterated entry validated a211ebc
system/bus.go:14-30

createEventBus returned on the first map-range entry — which bus became the system bus was random per process, and an unknown driver elsewhere in the map was never checked. Fix: validate every entry first, then select deterministically; unknown driver anywhere fails New() with ErrUnknownBusDriver.

P1-4 · Fan-out buses leaked on Close a211ebc
system/bus.go:35-52 + constructor.go:208-210

buildPublisher created N fresh in-process watermill buses per publish target, reachable only via the positional MultiBus.Publishers() dig, and never closed them. Fix: each fan-out bus is registered as a named closer; regression test proves Publish fails on a fan-out bus after Close().

P1-5 · volatile-source-of-truth warning unackable a211ebc
system/scream_store.go:101-122 · regression: system_phase3_test.go

The rule emitted a bare volatile-source-of-truth key while the documented ACK convention (config_loader.go:33-34) and the adjacent durability rule both use rule:target. Operators could never silence it. Fix: key is now volatile-source-of-truth:<role> and guarded by isAcknowledged; un-acked message text unchanged.

P2 — Config Integrity (14)

P2-7 · Typo'd projection engine silently dropped projections a211ebc
system/constructor.go:141-153

Unresolved engine names in the projections instance were skipped without error — the system started with no projections. Fix: New() returns ErrUnknownEngine listing the unresolved names.

P2-8 · Engine creation order nondeterministic a211ebc
system/constructor.go:57-65

Map-iteration order decided which engine was created first, which error surfaced first between two bad engines, and EngineNames() output. Fix: sorted-name creation; EngineNames() pinned stable across 10 boots.

P2-1/2 · lookupSeq / lookupSeqToken swallowed journal errors 449e0e5
system/adapter_event_journal.go:96-99,133-136

A failed journal scan resolved the resume cursor to 0 → projection catch-up silently restarted from the beginning and replayed already-processed events. Fix: both lookups propagate errors; a zero cursor skips the scan entirely on both position and token paths (cold start can no longer fail on an unrelated scan).

P2-3 · seqCache unbounded map 449e0e5
system/adapter_event.go:40-41

Event-ID → seq map grew without bound for the process lifetime. Fix: otter cache, MaximumSize 4096 (documented choice); mutex dropped (otter is concurrency-safe).

P2-4 · WARN diagnostics invisible post-construction 449e0e5
system/constructor.go:276-296 + system.go

Nothing in New() surfaced or blocked on WARN findings; ScreamReport() recomputed only config checks (dropping plan-drift warnings). Fix: construction-time report (config + manifest drift) stored on the System and returned by ScreamReport(); zero-value Systems keep the recompute fallback.

P2-5/6 · Dead RoleCommands/RoleQueries conditions 449e0e5
system/constructor.go:117,126

Inside isSourceOfTruth (only SOT/events roles) the == RoleCommands/== RoleQueries disjuncts could never fire. Removed with a pointer to the routed role-wiring proposal; behavior unchanged.

P2-9 · Durability declared but not wired routed
system/config_types.go (DurabilityTier) vs constructor

durability is parsed, checked by one scream rule, and otherwise ignored — no per-engine pragma/durability mapping exists. Routed: per-engine pragma mapping proposal.

P2-10 · Reserved config fields silently unused routed
system/config_types.go — BusConfig.Mode, InstanceConfig.Subscribe/Collections, CacheConfig.Engine

Documented in YAML examples (README shows mode: sync) but never read at runtime. Routed: implement-or-deprecate table per field.

P2-11 · Replace directives shadow published versions routed
system/go.mod:118-128

Six local replaces: metaengine v4.10.0→local (local is ≥12 commits past published v4.11.0: MariaDB generated-column layout, vector ADT, CBOR-default unification), 4 engine adapters v4.0.1→local, watermill v4.4.0→local. Local tests exercise unpublished code; fixes landed here are NOT in published system/v4.4.0 — a system/v4.5.0+ release (coordinated with a metaengine release) is required to ship them. go mod tidy applied (eventtest test dep was missing).

P2-12 · README overstates scream-store coverage
system/README.md:356-357

"warn about … missing durability" — no such rule exists (only volatile-memory and Relaxed-downgrade rules). Recorded here; wording deliberately left until the Durability wiring lands.

P2-13 · Postgres/duckdb integration tests not runnable in this environment
system/integration_postgres_test.go, system/integration/duckdb_test.go

Postgres tests skip without POSTGRES_TEST_DSN (skip logic verified correct); duckdb requires CGo + the integration sub-module (structure reviewed, sound: keeps CGo deps out of system/go.mod). Recorded as not-run, not as passed.

P2-14 · cqrs-lint C025 batch: 7 fmt.Errorf without %w
introspection.go:180, introspection_extended.go:79, projection_builder.go:77/106/138, query_constructors.go:103 (+1)

Audited individually: all are false positives — the format operands are strings or type names, with no underlying error to wrap (e.g. WorkerState.LastError is a string). Left in place; noted so future runs are not "fixed" into noise.
