01The Goal

The developer declares ONLY Commands + Events + Queries and their relationships. The operator decides infrastructure at DEPLOYMENT time via DeploymentConfig. system.System (single composition root) + metaengine (cost-based ES-native planner) derive everything else: projections, layouts, routing, indexes. Every engine serves every query — the planner warns, never blocks. App code never imports a storage backend. One composition root, one read-model API, zero storage-layer thinking.
