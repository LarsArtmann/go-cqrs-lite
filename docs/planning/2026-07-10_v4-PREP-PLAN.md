2. **Phase 3** (ADR-0044): The prerequisite blocker for v4 codec flip. Must complete before Phase 9.
3. **Phase 4** (Features): Consumer-requested, high-value. Independent of each other.
4. **Phase 5** (v4 Prep): Mechanical work that makes the v4 cut easy. Quick wins.
5. **Phase 6** (json Audit): Correctness improvements. CRITICAL items first (signing, encryption, external input).
6. **Phase 7-8** (Tests + Parallelism): Test parity and consumer-requested feature.
7. **Phase 9** (v4 Execution): BLOCKED on Phase 3. Execute as coordinated release.
8. **Phase 10-13** (Polish, Perf, Transport, Release): Lower urgency, can be done anytime.
