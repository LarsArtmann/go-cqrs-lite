01Key Findings (plan-altering)

BuildFlow blocker is a missing packages.default

.buildflow.yml has no explicit nix step — BuildFlow's default full mode runs nix build ., which fails: "flake does not provide attribute packages.x86_64-linux.default". Fix = add a packages.default (e.g. a cqrs-gen wrapper) via flake-parts perSystem, or a buildflow skip key.

Tagging is non-trivial (multi-module)

idempotency/go.mod requires event/v3 v3.3.0 + command/v3 v3.3.0 (+ transitive: id, codec, schema…). v3.3.0 tags for those don't exist yet. The "tag v3.3.0" step needs the full tag set, not one tag.

Doc drift: module count disagrees with itself

Real count = 49 go.mod files. AGENTS.md says 49 (correct). FEATURES.md header still says 45 (stale, pre-idempotency). FEATURES.md also omits the dispatch-DLQ as a feature. A reconciliation pass is owed.

Reliability trio status

DLQ (dispatch) = DONE Idempotency = DONE (module + middleware) Outbox = NOT STARTED (A2). The trio is ⅔ complete; only the optional outbox sink remains.

SSE has a better implementation trapped downstream

cqrs-htmx/sse_event.go has branded SSEEventID + zero-alloc WriteSSEEvent — better than go-cqrs-lite/transport/http/sse_event.go. Promote upstream, then delegate. Blocked on v3.3.0 tag.
