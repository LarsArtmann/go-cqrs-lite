01Self-Critique — What I Missed

I missed the biggest gaps entirely

In my initial analysis I claimed storage and decider were instrumented (true) but never checked transport/http, transport/grpc, and watermill. Verified: all three emit zero spans. These are the integration points where distributed tracing is most valuable — the broker boundaries where context must propagate across processes. This is a bigger gap than the missing bundle function.

I didn't cite the canonical pattern

I proposed a bundle function from intuition. I should have grounded it in the otel-contrib canonical pattern: every official instrumentation (otelhttp, otelgrpc, otelsql) uses functional options (opts ...Option), exposes WithTracerProvider/WithMeterProvider/WithPropagators, and defines a ScopeName constant + Version() function. Our otel/ module follows none of this convention yet.

I dismissed existing code I should have reused

prometheus.Setup() is our own existing template for the otel.Setup() helper — same shape, same option pattern. The existing CommandTracing/EventTracing/QueryTracing are the correct building blocks for the bundle; it's pure assembly, no new instrumentation logic. I should build on these, not invent parallel APIs.

Type model smells I overlooked

MetricsRecorder.Observe(ctx, name, duration, labels ...string) is stringly-typed — alternating key-value string pairs, no compile-time safety. The three parallel metrics APIs (MetricsRecorder, OTelMetrics, OTelMetricsWithCounter) with no clear primary is a split-brain. These need consolidating with typed attributes.

02Research Findings

Canonical Go OTel pattern (verified)

Every official go.opentelemetry.io/contrib instrumentation follows the same shape: 

// Functional options + integration at the library's native extension point
func NewHandler(handler http.Handler, operation string, opts ...Option) http.Handler

// Required by contrib guidelines:
const ScopeName = "go.opentelemetry.io/contrib/..."
func Version() string

Shared elements across otelhttp/otelgrpc/otelsql: WithTracerProvider, WithMeterProvider, WithPropagators, ScopeName, Version(). Our otel/ has Name but no Version() and no option-type provider injection.
