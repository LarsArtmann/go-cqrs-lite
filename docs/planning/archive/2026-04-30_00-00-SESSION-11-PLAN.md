8. **Error message grammar inconsistent** — "registering handler" vs "register handler"
9. **`AddServiceToDomain` silently no-ops in builder, errors in registry** — behavioral divergence

## Key Design Decisions

### Repository: Functional Options Pattern

```go
type RepositoryOption func(*EventSourcedRepository)

func WithSnapshotStore(store event.SnapshotStore) RepositoryOption
func WithOutbox(outbox event.Outbox) RepositoryOption

func NewRepository(store event.Store, bus event.Bus, opts ...RepositoryOption) *EventSourcedRepository
```

This allows any combination: bare repo, snapshot-only, outbox-only, or both.

### ApplySnapshot on Root

```go
type Root interface {
    // ... existing methods ...
    ApplySnapshot(state []byte) error
}
```

The repository calls `root.ApplySnapshot(snapshot.State)` after loading. The aggregate deserializes its own state.

### Middleware Caching

Store the fully-wrapped handler in `BaseDispatcher.handlers` instead of the raw handler. `Dispatch` becomes a direct map lookup + call, no middleware application.

### MemoryOutbox Cleanup

After `Ack`, remove acked entries from the slice. This is O(n) but correct for a test utility. Document that production implementations use SQL DELETE.
