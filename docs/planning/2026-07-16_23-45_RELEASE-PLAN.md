### 19 Modules with v4.0.0 tags + post-v4 changes (patch/minor bump)

**Tier A — Real bug fixes (v4.0.1):**

- `projectionhost/v4.0.1` — Status sort fix, stagger-shutdown leak fix, purgeDLQ init
- `watermill/v4.0.1` — EventBus dispatch deadlock fix
- `transport/http/v4.0.1` — depends on event/middleware changes

**Tier B — New features (v4.0.1, additive):**

- `storage/v4.0.1` — IS NULL operators, RawWhere, ViewUpdater, BLOB support
- `kv/v4.0.1` — new OpIsNull/OpIsNotNull (dependency of storage/view changes)

**Tier C — Metadata normalization / dep pinning only (v4.0.1):**

- `event/v4.0.1`, `decider/v4.0.1`, `middleware/v4.0.1`, `signing/v4.0.1`, `encryption/v4.0.1`, `listing/v4.0.1`, `codec/v4.0.1`, `otel/v4.0.1`, `schema/v4.0.1`, `snapshot/v4.0.1`, `id/v4.0.1`, `graph/v4.0.1`, `scenario/v4.0.1`, `scheduling/v4.0.1`

### Semver justification

- No breaking API changes since v4.0.0 (verified: no removed exports)
- All changes are bug fixes (patch) or additive features (minor → patch since pre-1.0 for stability)
- Tier C modules only have go.mod normalization — technically patch but low urgency
