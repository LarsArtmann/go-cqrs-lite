## Implementation Leakage

## Strengths

- Clean `Handler` naming: `event.Handler`, `command.Handler`, `query.Handler`, `middleware.Handler[M]` — each in its own package with context-appropriate signatures
- Branded IDs: `id.Of[T]`, `TodoID`, `UserID`, `AggregateID`, `EventID` — excellent domain alignment
- Error taxonomy: `ErrNotFound`, `ErrConflict`, `ErrVersionConflict` — honest, descriptive
- Event names use past tense: `UserCreated`, `UserDeleted` — domain-aligned
- `ImmutableEvent` — clearly communicates the design intent
- `AggregateRef` — precise domain term for aggregate type + ID pair
- No Hungarian notation, no cryptic abbreviations
- Consistent `New*` constructor pattern across all modules
- `Store = EventSink + EventSource` — honest ISP split, well-documented in ADR-0006
