## What T18b was

Close the benchmark-regression gate after the Go 1.27.1 toolchain bump: a
re-pinned baseline under the new toolchain kept failing on noise, and the
gate's own semantics (which metrics gate, when saving is allowed, how many
attempts are honest) had accumulated three rounds of owner rulings that
needed encoding, not re-litigating.

## The four gate-semantics changes (owner-ruled, encoded)

1. **`write_p99_ns` demoted from the noise-headline set** — defaults now
   `write_throughput write_p50_ns load_p50_ns`
   (`scripts/benchmark-regression.sh` NOISE_HEADLINE). Evidence: p99 CoV
   11.5–54% across five runs including deep-quiet and repeat-7, while the
   stable trio stayed <10% everywhere; max (22.9–53.9%) is WORSE than p99,
   which refuted the earlier "p50+max pair" option with the arc's own data.
2. **`--save` refuses on a failing run; `--force-save` is the explicit
   override** — a failing gate can no longer silently re-pin itself
   (mutation-tested: noise-fail + `--save` must refuse).
3. **Bounded attempts** — quiet-window runs retry a failing command up to
   `--attempts` (default 3) with fresh windows; a deterministically failing
   command must not burn windows forever.
4. **Per-suite `benchtime::count` budgets** — suites declare their own
   sampling budget instead of one global benchtime (the matview "lottery":
   short-budget suites flip variants on noise; report #3 quantified it).

Plus the surrounding machinery, all promoted and self-tested:
`quiet-window-run` (load-gated wrapper, `--self-test`), `nightly-bench`
flake apps, known-flaky annotation with expiry, baseline archival on
supersede, CI-parity rewrite, nightly-only fallback installer.

## The widening rule (the closure mechanism)

A failing-at-default-budget suite may widen to the next budget step
(`5x → 20x → 100x` per-suite `benchtime::count`) ONLY after its noise is
attributed (load-storm, reboot, toolchain change) rather than a regression;
the closure chain widened to `100x/9`, re-pinned, then verified green in the
same window. Old-budget medians remain comparable (11313 ns @ 100x/5 vs the
new 100x/9 series — within run noise; report #5 §B2).
