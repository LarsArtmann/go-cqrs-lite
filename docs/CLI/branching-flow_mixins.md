## branching-flow mixins

Analyze O(n²) mixin composition opportunities

### Synopsis

mixins analyzes Go source code to detect O(n²) mixin composition opportunities.

This tool identifies structs with overlapping fields that suggest
opportunities for mixin extraction and reuse.

Example:
branching-flow mixins ./src
branching-flow mixins --min-confidence high ./src
