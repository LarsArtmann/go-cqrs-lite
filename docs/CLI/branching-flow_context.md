## branching-flow context

Analyze Go code for semantic context loss in error handling

### Synopsis

context analyzes Go source code to detect semantic context loss
in error handling. It helps identify where critical context variables
(user IDs, request IDs, etc.) are lost when errors are returned.

This tool identifies:

- Immediate context loss (error created without context)
- Cross-function context loss (context not passed through)
- Delayed recovery (context recovered too late)

Examples:
branching-flow context ./src
branching-flow context --format html --output report.html ./src
branching-flow context --severity critical ./src

```
branching-flow context <path> [flags]
```
