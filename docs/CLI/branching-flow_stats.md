## branching-flow stats

Run all analyzers and show summary statistics

### Synopsis

stats runs all branching-flow analyzers on a codebase and displays
a consolidated summary of findings across all analysis types:

- Semantic context loss in error handling
- Composition-over-inheritance patterns
- Phantom type opportunities
- Duplicate type detection
- Panic condition analysis
- Strong ID type analysis

This provides a quick overview of code quality without running
each analyzer individually.

Examples:
branching-flow stats ./src
branching-flow stats --format json ./src
branching-flow stats --verbose ./src

```
branching-flow stats <path> [flags]
```
