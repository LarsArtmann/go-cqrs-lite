## branching-flow boolblind

Analyze Go code for structs with multiple bools that should be bit flags

### Synopsis

boolblind analyzes Go source code to detect boolean blindness anti-patterns.

This analysis identifies structs with multiple bool fields that could be
consolidated into efficient bit flags, reducing memory usage and improving
type safety.

Boolean blindness occurs when multiple independent boolean states are stored
as separate bool fields instead of using bit flags. This wastes memory and
makes the code harder to maintain.
