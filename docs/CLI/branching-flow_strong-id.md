## branching-flow strong-id

Find function parameters with 'id' in the name that should use strong ID types

### Synopsis

strong-id analyzes Go source code to detect function parameters containing 'id'
in their name that are currently typed as string or primitive types, and suggests
replacing them with strong ID types from github.com/larsartmann/go-composable-business-types/id.

This analysis identifies:

- Parameters like 'userId', 'orderId', 'requestId' typed as string
- Struct fields with 'id' in the name that should be strong types

Strong ID types prevent mixing different entity IDs at compile time:
type UserID = id.ID[UserBrand, string]
func ProcessUser(id UserID) { ... }

For usage examples and API documentation, see:
https://github.com/larsartmann/go-composable-business-types/tree/main/id

Examples:
branching-flow strong-id ./src
branching-flow strong-id --format json ./src > strong-ids.json
branching-flow strong-id --format markdown ./src > strong-ids.md
