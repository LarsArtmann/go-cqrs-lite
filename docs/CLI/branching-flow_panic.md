## branching-flow panic

Analyze Go code for potential panic conditions

### Synopsis

panic analyzes Go source code to detect potential panic conditions
and suggests error handling alternatives.

This tool identifies:

- Explicit panic() calls (should return errors instead)
- Type assertions without ok checks
- Channel operations that may panic
- Potential nil pointer dereferences
- Array/slice index out of range
- Division by zero

Examples:
branching-flow panic ./src
branching-flow panic --severity high ./src
branching-flow panic --json ./src

