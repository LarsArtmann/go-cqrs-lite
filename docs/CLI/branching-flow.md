## branching-flow

Analyze Go code for semantic context loss in error handling

### Synopsis

branching-flow is a tool that analyzes Go source code to detect
semantic context loss in error handling. It helps identify where critical
context variables (user IDs, request IDs, etc.) are lost when
errors are returned.

Available Commands:
context Analyze semantic context loss in error handling
dupe Find duplicate or similar interface/struct definitions
phantom Analyze phantom type opportunities
panic Analyze potential panic conditions
strong-id Find parameters with 'id' in the name that should use strong ID types
boolblind Analyze structs with multiple bools that should be bit flags
anti-patterns Analyze O(n) structural anti-patterns
mixins Analyze O(n²) mixin composition opportunities
all Run all linters and show combined results
stats Run all analyzers and show summary statistics

Use "branching-flow <command> --help" for more information about a command.
