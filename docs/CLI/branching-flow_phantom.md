## branching-flow phantom

Analyze Go code for primitive types that should be phantom types

### Synopsis

phantom analyzes Go source code to detect primitive type usages
that should be wrapped as phantom types for type safety.

This analysis identifies:

- string types representing domain concepts (IDs, emails, etc.)
- int/float types with semantic meaning (counts, percentages, etc.)
- bool types that should be enums

Phantom types prevent mixing semantically different values of the same
primitive type, catching bugs at compile time instead of runtime.

Examples:
branching-flow phantom ./src
branching-flow phantom --format json ./src > phantom-types.json
branching-flow phantom --format markdown ./src > phantom-types.md
