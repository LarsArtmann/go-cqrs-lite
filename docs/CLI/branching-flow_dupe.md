## branching-flow dupe

Find duplicate or similar interface/struct definitions

### Synopsis

dupe analyzes Go source code to detect duplicate or similar type definitions.
Types with identical method signatures (for interfaces) or field signatures (for structs)
are flagged as potential duplicates.

This analysis identifies:

- Interfaces with identical method signatures but different names
- Structs with identical field signatures but different names
- Generic vs non-generic pairs (e.g., Cache[T] vs CacheString)

Examples:
branching-flow dupe ./src
branching-flow dupe --format json ./src > duplicates.json
branching-flow dupe --format markdown ./src > duplicates.md

```
branching-flow dupe <path> [flags]
```

      --exit-code                           Exit with code 1 if duplicates are found
      --format report format                Report format (console, json, markdown, sarif) (default console)

      --verbose verbosity level[=Verbose]   verbosity level (Silent, Normal, Verbose) (default Normal)
