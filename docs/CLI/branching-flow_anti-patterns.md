## branching-flow anti-patterns

Analyze O(n) structural anti-patterns

### Synopsis

anti-patterns analyzes Go source code to detect O(n) structural anti-patterns
that violate composition-over-inheritance principles.

This tool identifies:

- Base/Abstract naming violations
- Large structs with too many fields
- Deep inheritance chains

Example:
branching-flow anti-patterns ./src
branching-flow anti-patterns --json ./src
