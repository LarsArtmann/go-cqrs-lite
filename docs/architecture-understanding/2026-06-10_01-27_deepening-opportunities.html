Architecture Deepening — go-cqrs-lite

2026-06-10 5 candidates

1. Deepen storage query engine

Strong
storage/event_store_load.go · storage/command_store_load.go · storage/sql/

Problem: loadParams, loadWithSpan, queryRows are copy-pasted between event and command stores (~300 lines of duplication).

Solution: Extract generic sql.QueryEngine[T] in storage/sql/. Each store provides a scan function.

  • Locality: query logic in one module
  • Leverage: two stores share one engine
  • Delete ~300 lines

2. Break the event-command cycle

Strong
event/go.mod · command/go.mod

Problem: event imports command (CatalogDispatcher) and command imports event (types, errors). Bidirectional cycle prevents independent versioning.

Solution: Move CatalogDispatcher to command/query. Remove event→command and event→query. event becomes zero-dep.

  • event becomes zero-dep domain module
  • Independent versioning actually works
  • 22 modules import event without pulling command

3. Extract eventtest as separate module

Strong
event/eventtest/ · event/go.mod · memory/go.mod

Problem: event/eventtest imports memory, creating event↔memory cycle.

Solution: Give eventtest its own go.mod. It depends on event and memory; neither depends on it.

  • Breaks event↔memory cycle
  • event go.mod drops memory dependency
  • Test helpers isolated from production

4. Extract HTTP from middleware

Worth exploring
middleware/sse.go · middleware/healthcheck.go · middleware/metrics_http.go

Problem: SSE broker, health check handler, and metrics HTTP share nothing with CQRS middleware. Importing middleware for retry brings in net/http.

Solution: Move to middleware/http/ sub-package.

5. Consolidate error taxonomy

Worth exploring
event/errors.go · command/errors.go

Problem: command/errors.go re-exports the entire error-family API (90% unused in production). decider correctly delegates to event.

Solution: Adopt decider's pattern everywhere. Remove command's dead re-exports (~60 lines).

Top Recommendation

Candidates 2 + 3 together — breaking event↔command + extracting eventtest eliminates 3 of 4 bidirectional cycles. event becomes a zero-dep domain module. Highest leverage change in the codebase.
