  • • Locality: retry bugs live in one module
  • • Delete 24 functions, add 8 generics + 3 adapters
  • • ~300 lines removed net

Top Recommendation

Start with Collapse Middleware Fan-Out. It's the single largest source of duplication (~500 lines), affects every consumer of the middleware module, and the fix is purely mechanical: generic Middleware[H] per concern with thin backward-compat adapters. Estimated effort: 2 hours. Impact: eliminates the module's defining quality problem.
