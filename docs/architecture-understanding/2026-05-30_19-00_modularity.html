Detailed Findings

HIGH

3 Module-Level Circular Dependencies via event/

event ↔ command, event ↔ memory, event ↔ schema. All caused by _test.go and eventtest/ imports. No package-level cycles, but go get .../event transitively pulls 5 extra modules into go.sum.

CycleRoot Cause FileFix
event ↔ commandevent/errors_taxonomy_test.go:11Move to integration/
event ↔ memoryevent/event_bdd_test.go:13Use test doubles
event ↔ schemaevent/eventtest/event_helpers.go:10Extract eventtest/snapshot
MEDIUM

decider/ → memory/ Layer Violation

Layer 3 imports Layer 4. Consumer wanting only the aggregate pattern pulls in-memory implementations transitively. Decider should accept interfaces, not concrete memory types.

MEDIUM

storage/ → listing/ Horizontal Coupling

Storage implements listing's AggregateReader interface. Consumer wanting only SQL event store gets listing + memory transitively. Consider registration pattern or shared contract module.

POSITIVE

3 Gold-Standard Modules

  • catalog/ — zero internal deps. 1-module import.
  • query/ — only dispatcher. 2-module import.
  • codec/ — pure leaf, zero deps.
  • pebble/ — minimal footprint (4 modules).
  • otel/ — zero internal deps, opt-in instrumentation.

Recommendations

1

Break event/ test cycles

Move cross-module test assertions to integration/. Use interface-based test doubles in event/eventtest/.

2

Remove decider/ → memory/ dependency

Accept store as interface. Wire memory at application layer.

3

Decouple storage/ from listing/

Move AggregateReader interface to shared contract or use registration pattern.
